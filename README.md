# Sistema Bancário

Projeto desenvolvido para estudo de Python.
Feito por um aluno independente, inicialmente com pouco conhecimento da linguagem.

## Objetivo

Criar um sistema bancário simples enquanto estudo conceitos de
programação e orientação a objetos.

A finalidade é absorver novos conhecimentos e aplicá-los no próprio sistema,
ampliando o projeto conforme novos conceitos são aprendidos.
